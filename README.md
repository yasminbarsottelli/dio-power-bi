# DIO - Power BI

Aqui ficam os projetos e desafios que fiz no curso de Power BI da DIO. Cada desafio tem a sua pasta, com os arquivos relacionados e um README explicando o que foi feito.

## Projetos

- [01 - Dashboard de Vendas](./01-dashboard-vendas): mapas e gráficos de vendas, lucro e unidades vendidas por país e segmento.
- [02 - Relatório de Lucro](02-relatorio-lucro): relatório com cascata, radar, medidor com meta, previsão e botões de alternância entre gráficos.
- [03 · Azure MySQL + Power BI](./03-azure-mysql-powerbi): Banco MySQL na Azure integrado ao Power BI, com tratamento dos dados no Power Query (junções, separação de colunas, agrupamento e tipos de dados).
- [04 · Star Schema de Professores](04-star-schema-professor): modelagem dimensional de uma universidade com foco em professor, com tabela fato, dimensões e dimensão de data por semestre, feita no MySQL Workbench.

Conforme os próximos desafios chegarem, vou adicionando por aqui... 😊
